# student-management-system
A C# console application for managing student records including adding, removing, searching and displaying students with grade tracking.

📋 Description
>A full-featured student records system built using OOP principles in C#. Supports dynamic student management with regex-based ID validation and average grade calculation. Built as part of my C# programming coursework at Eduvos.

✨ Features
>Add new students with ID, name, and multiple grades

>Remove students by ID

>Search for a specific student by ID

>Display all students with their calculated average grade

>Regex validation enforces correct student ID format (e.g. S12345)

>Exception handling for invalid inputs

🛠️ Built With
>Language: C# | Platform: .NET Console Application

🚀 How to Run
>Clone the repository

>Open the project in Visual Studio or any C# IDE

>Build and run StudentManagementSystem.cs

>Use the menu options to manage student records

💡 Concepts Demonstrated
>Object-oriented programming with constructors and destructors

>Static constructors and static fields

> List<T<T>>  generic collections

>Regex for input validation

>Lambda expressions (List.Find)

>Auto-implemented properties

>Exception handling
